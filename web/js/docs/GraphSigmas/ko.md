# 시그마 그래프

연결된 각 시그마 스케줄을 ComfyUI `IMAGE`로 렌더링합니다.

- **입력 개수**: 서로 대응하는 `SIGMAS` 입력과 `IMAGE` 출력을 추가합니다.
- **어두운 테마**: 그래프의 어두운 배경과 밝은 배경을 전환합니다.
- **미리보기 해상도**: 450×300, 600×400, 900×600, 1200×800 출력 중에서 선택합니다. 워크플로 호환성을 위해 기본값은 600×400이며 문자, 선, 점도 출력 크기에 맞춰 비례 조절됩니다.

각 이미지 출력을 이미지 미리보기 또는 저장 노드에 연결하세요. 동적 출력 위치를 유지하기 위해 입력이 없는 자리에는 작은 빈 이미지를 출력합니다.
