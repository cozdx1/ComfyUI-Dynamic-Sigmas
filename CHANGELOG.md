# Changelog

## [1.1.0] - 2026-09-15

- Added model profiles for Illustrious/SDXL, Anima, WAN, LTXV, Z-Image, Qwen-Image, Flux2, Krea2, and Custom.
- Added 11 scheduler curves, including `beta57` and `bong_tangent`.
- Added endpoint, per-step, curve-shaping, and smoothing controls.
- Added multiple output resolutions to Graph Sigmas.
- Added a `SIGMAS` to `SCHEDULER_FUNC` bridge for compatible nodes such as Impact Pack Detailers.
- Added Korean localization and v1.0.0 workflow migration.

## [1.0.0] - 2026-03-30

- Initial release with Dynamic Sigma Scheduler, Graph Sigmas, and Concat Sigmas.
